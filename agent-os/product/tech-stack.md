# Product Tech Stack

## Framework & Runtime
- **Application Framework:** Laravel 12.x
- **Language/Runtime:** PHP 8.4.16
- **Package Manager:** Composer (PHP), NPM (JS)

## Frontend
- **JavaScript Framework:** Alpine.js (via Livewire/Filament)
- **CSS Framework:** Tailwind CSS v4
- **UI Components:** Filament PHP v3 (Admin Panel & Form Builder), Flux UI (Free Edition), Blade Components
- **Full Stack:** Livewire v3 (Server-driven UI), Livewire Volt v1 (Single-file components)

## Database & Storage
- **Database:** MySQL / SQLite
- **ORM:** Eloquent ORM
- **Caching:** File/Redis

## Testing & Quality
- **Test Framework:** Pest v4 (Unit, Feature, and Browser tests)
- **Linting/Formatting:** Laravel Pint

## Deployment & Infrastructure
- **Hosting:** Standard LAMP/LEMP stack or PaaS (e.g., Forge)
- **CI/CD:** GitHub Actions

## Third-Party Services
- **Authentication:** Laravel Fortify v1 / Filament Breezy
- **Roles/Permissions:** Filament Shield v3
- **Media:** Spatie Media Library
- **Logging:** Spatie Activity Log / Filament Logger
